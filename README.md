# LabelFolio

Official website, support, and privacy policy for LabelFolio, a native label designer for Apple silicon Macs.

- [Website](https://mosher23.github.io/LabelFolio/)
- [Support & printer compatibility](https://mosher23.github.io/LabelFolio/support.html)
- [Privacy policy](https://mosher23.github.io/LabelFolio/privacy.html)
- [Report a problem](https://github.com/Mosher23/LabelFolio/issues)

## About this repository

This repository contains the public static website and support material. App source code, signing assets and private user content are not included.

NIIMBOT B1 Pro monochrome Bluetooth printing has been physically tested. Other model profiles are experimental; support depends on the model and firmware. See the support page before choosing hardware.

## Publishing

GitHub Pages serves the main branch from the repository root. The site uses plain HTML and CSS, system fonts, no external scripts, and system light/dark appearance.

## Support privacy

Issues are public. Do not post Wi-Fi passwords, private label documents, personal photos or other sensitive information.
